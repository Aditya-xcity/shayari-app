Shayari Player

A minimal, music-inspired Shayari player where every verse feels like a song.

Features
Browse through different Shayari
Previous and next Shayari controls
Play/pause music
Music progress bar
Mood and author information
Vinyl-inspired interface
Responsive design
Tech Stack
HTML
CSS
JavaScript
JSON for Shayari and music data
Run Locally

Clone the repository and open index.html in your browser.

git clone <repository-url>
cd shayari-player

No build tools or dependencies are required.
